準備

まずは道具をそろえる

難しい設定はありません。ダウンロードして、空の五線譜を1枚用意するところまでやります。

1

MuseScore をインストールする

公式サイト musescore.org/ja/download から最新版(現在 4.7)をダウンロードします。無料です。Windows / Mac それぞれのボタンを押すだけ。

途中で「Muse Sounds(高品質な音色)」を勧められます。あれば音が綺麗になりますが、なくても問題なく作曲できます。容量が気になればスキップでOK。

2

新しい楽譜をつくる

起動したら「ホーム」画面が出ます。左上の 新しいスコア(または ファイル→新規)を選び、ウィザードに沿って進めます。

  • 楽器: まずは「ピアノ」を1つだけ選ぶ(検索欄に "piano")
  • 調号(キー): いちばん簡単なハ長調=シャープもフラットも無しを選択
  • 拍子: 4/4 のまま
  • テンポ: 90〜100 くらい(あとで変えられます)

「完了」を押すと、空の五線譜が出てきます。これがあなたの作曲台です。

POINT分からない項目は全部そのまま「完了」でも大丈夫。あとからいくらでも直せます。止まらないことが一番大事。
3

「再生」ボタンの場所を覚える

画面上の ▶ ボタン、またはキーボードの Space で、書いた音が鳴ります。今は空っぽなので何も鳴りませんが、「ここを押せば聴ける」とだけ覚えておきましょう。これから何度も使います。

第 1 章

はじめての一曲を“完成”させる

理論はまだ要りません。あなたの強み=楽譜を読む力を使って、誰でも知っている「きらきら星」を打ち込み、最後まで仕上げます。

1

音符入力モードに入る

楽譜のいちばん左の最初の休符を1回クリックして青く選び、キーボードの N を押します。これで音符入力モード(打ち込みモード)になります。もう一度 N か Esc で抜けられます。

2

入力の2つのルールを覚える

MuseScore の打ち込みは、たった2ステップの繰り返しです。

  • ① 長さを数字で選ぶ: 5=四分音符、6=二分音符(4=八分、7=全音符)
  • ② 音名をアルファベットで打つ: C=ド、D=レ、E=ミ、F=ファ、G=ソ、A=ラ、B=シ

つまり「四分音符のド」なら 5 → C。長さを変えない限り、次からは音名キーだけ押せばOK。休符は長さを選んで 0 です。

音がずれたら入力した音が高すぎ／低すぎたら、その音を選んで ↑ ↓ で半音ずつ、Ctrl+↑↓ で1オクターブ動かせます。
3

「きらきら星」を打ち込む

下のレシピ通りに、左から順に音名キーを押していくだけ。基本は四分音符(5)、各フレーズ最後の黄色だけ二分音符(6)です。

♪ きらきら星(ハ長調 / 4分の4拍子)

きらきら ひかる
ド Cド Cソ Gソ Gラ Aラ Aソ G
おそらの ほしよ
ファ Fファ Fミ Eミ Eレ Dレ Dド C
まばたき しては
ソ Gソ Gファ Fファ Fミ Eミ Eレ D
みんなを みてる(同じ)
ソ Gソ Gファ Fファ Fミ Eミ Eレ D
きらきら ひかる(くり返し)
ド Cド Cソ Gソ Gラ Aラ Aソ G
おそらの ほしよ(くり返し)
ファ Fファ Fミ Eミ Eレ Dレ Dド C

最初の C を打ったとき音が高すぎたら、Ctrl+↓ で真ん中の「ド」に下げてから続けましょう。

4

聴いて、直して、完成にする

N か Esc で入力モードを抜けてから Space で再生。間違えた音はクリックして ↑↓ で直せます。音符を消したいときは選んで Delete(休符に戻ります)。

ちゃんと「きらきら星」に聞こえたら——おめでとう、これがあなたの完成した1曲目です。「自分でも音楽を鳴らせた」という感覚を、まず味わってください。

5

保存して、書き出す

Ctrl+S(Mac は ⌘+S)で保存。ファイル→エクスポート から PDF(楽譜)や MP3(音源)として書き出せます。誰かに聴いてもらうのも、上達の燃料になります。

第 2 章

コードってなに?(完成した曲で体感する)

いよいよ正体不明だった「コード」へ。でも先に図と耳で理解してから、さっきの「きらきら星」に伴奏として乗せます。難しい暗記はしません。

1

コード=音を“3つ重ねたもの”、それだけ

コードとは、同時に鳴らす複数の音のかたまりです。基本は1つ飛ばしに3つ重ねる=「ド・ミ・ソ」。これが C(シー) というコードの正体です。

ド・ミ・ソを縦に重ねた和音 = コード「C」
2

明るい(メジャー)と暗い(マイナー)

真ん中の音をほんの少し下げる(ミ→ミ♭)だけで、響きが明るい→切ないに変わります。これがメジャーとマイナーの違い。理屈より、鍵盤で見ると一発です。

C メジャー(明るい)
C マイナー(切ない)
真ん中の音が半音違うだけ。MuseScore で両方鳴らして、響きの差を耳で確かめてみて。
3

ハ長調で使える“7つのコード”

「きらきら星」のキー=ハ長調の音(ドレミファソラシ)それぞれの上に、さっきの“1つ飛ばし3段重ね”をすると、自動的に7つのコードができます。覚えなくてOK、眺めるだけ。

C明るい
Dm切ない
Em切ない
F明るい
G明るい
Am切ない

この中でも特に大事な“三本柱”が C・F・G。この3つだけで、童謡や賛美歌の多くは伴奏できてしまいます。

なぜ C・F・G が“三本柱”なの?
C は「家(安定)」、G は「家に帰りたくなる緊張」、F は「その中間のふくらみ」。この3つを行き来すると、人間の耳が自然に感じる“出発→緊張→解決”の流れが作れるからです。難しい用語(トニック・ドミナント・サブドミナント)は、今は知らなくて大丈夫。
4

「きらきら星」にコードを書き込む

1曲目のメロディの上に、コードネームを表示してみましょう。音符を1つ選んで Ctrl+K(Mac は ⌘+K)を押すと、音符の上に文字が打てる状態になります。「C」と打って Space を押すと、次の音符へ進みます。

各小節のアタマに、だいたい次のコードを当てると合います:

♪ きらきら星 コード付け(目安)

きらきらひかる
CFCG
おそらのほしよ
CGCG

コードを入れたら Space で再生。MuseScore 4 はコードネームも音で鳴らせます(メニューの再生設定でコード記号の再生をオンに)。メロディだけのときと、響きの厚みがどう変わるかを聴き比べてください。これが「伴奏が付く」という感覚です。

自由にやろう「ここは F じゃなく G のほうが好き」と感じたら、それが正解です。コードに“絶対”はありません。気持ちよく聞こえる方を選ぶ——その耳を育てるのが作曲です。
第 3 章

コード進行から、新しい曲をつくる

今度は“真似”ではなく、ゼロからオリジナル。といっても順番は逆——先にコードの土台を置いて、その上にメロディを乗せます。これがプロもよくやる作り方です。

1

「コード進行」=コードの並び順

コードを順番に並べたものをコード進行と呼びます。世の中の曲の大半は、実は数種類の“定番進行”の組み合わせ。まずは下のどちらかを選んでみましょう。

王道進行(明るく前向き)

C
→
G
→
Am
→
F

50s進行(どこか懐かしい)

C
→
Am
→
F
→
G
2

土台のコードを打ち込んでループ再生

新しいスコア(ハ長調・4/4)を作り、各小節に全音符(7)で和音を置きます。和音は、音名を1つ打ったあと Shift を押しながら他の音を足すと縦に重なります。例:Cなら C → Shift+E → Shift+G。

選んだ4つを1小節ずつ、計4小節。Space でループ再生しながら、しばらく聴いて“体になじませて”ください。鼻歌が自然と出てきたら大成功。

もっと手早くやりたい
和音を縦に積むのが面倒なら、いったん各小節のアタマに Ctrl+K でコードネーム(C / G / Am / F)を書くだけでもOK。再生設定でコード記号の再生をオンにすれば、それだけで土台が鳴ります。
3

メロディを“乗せる”コツ

真っ白からメロディを思いつくのは難しいので、ヒントを2つ。

  • 小節のアタマは、そのコードの音から始める。 Cの小節なら ド・ミ・ソ のどれか。これだけで「外れない」メロディになります。
  • あいだは隣の音へなめらかに動かす。 跳ばずに、ドレミと階段状に動くと歌いやすい旋律に。

別のパート(または同じ譜の上の声部)に、四分音符・八分音符を混ぜて8小節ほど。完璧を目指さず、まず最後まで埋めること。

迷ったら最初の音と最後の音を「ド」にすると、不思議とまとまって聞こえます。終わりが決まると曲は一気に“それっぽく”なります。
4

“形”を与えて、2曲目を完成させる

同じ4コードをもう1回くり返して、前半をAメロ、後半を少し高めに動かしてサビ、のように8小節+8小節に。最後の小節は長め(二分・全音符)にすると、ちゃんと“終わった感”が出ます。

再生して気持ちよければ、それで完成。Ctrl+S で保存し、書き出して残しましょう。これがあなたの初オリジナル曲です。

第 4 章

これから、どう伸ばすか

2曲完成したあなたは、もう“作曲を始めた人”です。次に進むときの地図を置いておきます。焦らず、興味の出たところから。

1

次に知ると世界が広がること

  • セブンスコード(C7, Cmaj7 など): 3音重ねにもう1つ足すと、おしゃれで切ない響きに。J-POPやジャズの色気の正体。
  • 転回形: 同じコードでも音の並び順を変えると、なめらかにつながる。
  • リズムとベース: 同じメロディでも、リズムを変えるだけで別の曲に化けます。
  • キー(調)を変える: ハ長調以外も試すと、表現の幅が一気に増えます。
2

いちばん効く練習法

好きな曲のコードを調べて、MuseScore で真似て打ち込む。 これが最強の教材です。「自分が良いと感じる曲は、どんなコードでできているのか」を手で確かめるうち、引き出しが自然に増えます。コードは検索すれば多くの曲のものが見つかります。

3

困ったときの場所

操作で詰まったら、MuseScore の公式ハンドブックや、画面の ヘルプ から探せます。日本語のチュートリアル動画も豊富です。1人で抱えず、調べながらで大丈夫。
